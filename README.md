Vrinda Store – Excel Data Analysis & Dashboard

Project Overview

This project analyzes Vrinda Store's sales data using Microsoft Excel to understand sales performance, customer behavior, and business trends.

Business Objective

* Analyze overall sales performance
* Identify top-performing categories and products
* Understand customer purchasing patterns
* Compare sales across different regions
* Create an interactive dashboard for business insights

Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Excel Formulas
* Data Cleaning
* Dashboard

Key Analysis

The project includes:

* Sales and order analysis
* Category-wise sales
* State/region-wise performance
* Customer analysis
* Monthly sales trends
* Top-performing products
* Interactive dashboard

Project File

`Vrinda_Store_Analysis.xlsx`

The Excel file contains the complete project, including the data, analysis, and dashboard.

Dashboard Preview

The dashboard provides a visual summary of the key business insights and performance metrics.

Key Insights

* Identified the best-performing categories and products
* Analyzed sales trends over time
* Compared performance across different regions
* Identified important customer purchasing pattern
